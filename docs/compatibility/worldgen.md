# 世界生成模组适配

[文档目录](../README.md)

世界生成兼容需要同时检查服务端生成快照、客户端重建与 Rust 计算。联机时服务端与客户端需要一起更新；源码已经修改与候选包已经包含分别记录。

## Tectonic 非默认预设：本轮源码修复

2026-10-30 的新增修复尚未打入当前 `voxy-update-20261029` 候选包，统一验证进行中。默认预设能预测，不能证明启用替代大陆／侵蚀缩放的 `I Use Voxy Btw` / `OVERKILL` 预设走相同的快照路径。

Tectonic 的配置噪声在创建时已经读取服务端配置。部分旧版实现的图遍历跳过节点自身，而来源 codec 只保留配置键、噪声与位移输入，未写出实际生效的缩放、倍数、偏移和 smoother 标志。直接依赖该 codec 会漏掉需要替换的嵌套节点，或在客户端按另一份配置重新求值。本轮源码显式捕获已应用参数并规范化嵌套图，客户端据此重建；Java 与 Rust 都支持该节点，保留 Rust 计算路径。

1.20.1 至 26.2 保持对应发布实现的 double 运算顺序；26.3 使用独立的 float 实现。Tectonic 3.0.32 的单点坐标先经过 float 乘加，体积路径则在 double 中组合坐标与位移，smooth 体积路径还省略偏移。适配保留这些实际发布行为，分别比较单点和体积结果，避免用一个看似等价的公式改变地形。该版本声明的范围与坐标依赖也按上游保留。

固定实际发布 JAR 的参数往返、嵌套图、非零偏移、边界坐标、Java / Rust 数值一致性分别验收；最终通过数量与产物身份见[阶段验证](../history/validation.md#尚未打包的源码改动)。本轮尚未据此声明使用这些预设的实际整合包地形、植被或帧时间已验收。

## 已有世界生成修复

以下六项为先前阶段已实施并记录验证的范围，本轮新增预设修复不自动继承它们的通过记录。

| 范围 | 修复后的行为 |
| --- | --- |
| 动态世界生成注册表 | 同步实际标签成员、成员顺序和空标签；客户端先恢复标签再解码引用。自定义注册表与快照携带的原版注册表采用同一流程，不改写客户端实时注册表。 |
| TerraBlender 末地 | 捕获服务端已初始化的四类加权区域、实际缩放层数和种子，Java / Rust 重放相同群系路由。保留对应发布版本的实际行为，不用客户端配置替代服务端状态。 |
| BetterEnd 26.3 | 使用实际地形 API 报告的采样网格，支持默认 8×4 和自定义插值尺寸，修正先前固定 1×1 的高度采样。 |
| 自定义 LOD provider | 真实区块捕获使用 provider 自己的群系 palette 按标识映射；palette 顺序不同不会误用旧缓存。 |
| 必需的 TerraBlender 路由 | 重建失败会明确停用该维度的预测；支持完整路由的 Java 后端仍可使用。原生初始化失败不会提前关闭待用的 Java 上下文。 |
| Lithostitched 26.3 | Rust 支持 2.0.6 的 fast_noise、sin、cos、shift、cellular 节点；分别匹配单点与体积采样的 float / 截断规则，并导出 merged 包装器实际执行的 full 图。 |

修正后的快照使用独立的成品缓存身份，避免继续读取旧标签、旧末地路由或错误群系编号生成的结果；不要求手动删除整个缓存目录。没有新标签字段的旧快照仍可读取。

这些是对应接口、快照和算法的兼容结论，不等于任意整合包内所有模组的植被、结构和画面均已实机验收。TerraBlender 1.20.1 的当前发布没有末地扩展 API，该版本继续使用普通区域适配；末地扩展的实际 JAR 回放检查按不适用记录。

验证输入、构建身份与通过／跳过数量见[阶段验证记录](../history/validation.md)。这些修复属于 Fabric 目标，不能据此声明 Forge / NeoForge 同样完成适配。
