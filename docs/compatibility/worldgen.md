# 世界生成模组适配

[文档目录](../README.md)

世界生成兼容需要同时检查服务端生成快照、客户端重建与 Rust 计算。联机时服务端与客户端需要一起更新；源码已经修改与候选包已经包含分别记录。

## Tectonic 非默认预设

`fabric-optional-20261030` 候选构建包含 Tectonic 的新增预设修复。`I Use Voxy Btw` / `OVERKILL` 会启用替代大陆／侵蚀缩放，与默认预设使用不同的快照路径。

Tectonic 的配置噪声在创建时已经读取服务端配置。部分旧版实现的图遍历跳过节点自身，而来源 codec 只保留配置键、噪声与位移输入，未写出实际生效的缩放、倍数、偏移和 smoother 标志。直接依赖该 codec 会漏掉需要替换的嵌套节点，或在客户端按另一份配置重新求值。本轮源码显式捕获已应用参数并规范化嵌套图，客户端据此重建；Java 与 Rust 都支持该节点，保留 Rust 计算路径。

1.20.1 至 26.2 保持对应发布实现的 double 运算顺序；26.3 使用独立的 float 实现。Tectonic 3.0.32 的单点坐标先经过 float 乘加，体积路径则在 double 中组合坐标与位移，smooth 体积路径还省略偏移。适配保留这些实际发布行为，分别比较单点和体积结果，避免用一个看似等价的公式改变地形。该版本声明的范围与坐标依赖也按上游保留。

固定实际发布 JAR 的参数往返、嵌套图、非零偏移、边界坐标、Java / Rust 数值一致性分别验收；通过数量与产物身份见[阶段验证](../history/validation.md#当前可选模组与-tectonic-构建)。1.20.1 / 3.0.17 与 1.21.11 / 3.0.19 的固定发行包没有替代缩放选项，默认节点与完整设置往返继续验证。玩家原整合包的地形、植被和帧时间仍需安装新构建后实机确认。

## 已有世界生成修复

FreeTerraForged 1.21.1 Fabric 新增 1.0.0015–1.0.0023 的 epoch、生成计划与过滤区块缓存适配，保留 1.0.0 和 ReTerraForged 0.0.6005 的瓦片路径。服务端群系替换配置与气候上下文随快照恢复；具体范围和验证边界见[专项说明](freeterraforged.md)。

以下六项为先前阶段已实施并记录验证的范围，本轮新增预设修复不自动继承它们的通过记录。

| 范围 | 修复后的行为 |
| --- | --- |
| 动态世界生成注册表 | 同步实际标签成员、成员顺序和空标签；客户端先恢复标签再解码引用。自定义注册表与快照携带的原版注册表采用同一流程，不改写客户端实时注册表。 |
| TerraBlender 末地 | 捕获服务端已初始化的四类加权区域、实际缩放层数和种子，Java / Rust 重放相同群系路由。保留对应发布版本的实际行为，不用客户端配置替代服务端状态。 |
| BetterEnd 26.3 | 使用实际地形 API 报告的采样网格，支持默认 8×4 和自定义插值尺寸，修正先前固定 1×1 的高度采样。 |
| 自定义 LOD provider | 真实区块捕获使用 provider 自己的群系 palette 按标识映射；palette 顺序不同不会误用旧缓存。 |
| 必需的 TerraBlender 路由 | 重建失败会明确停用该维度的预测；支持完整路由的 Java 后端仍可使用。原生初始化失败不会提前关闭待用的 Java 上下文。 |
| Lithostitched 26.3 | Rust 支持 2.0.6 的 fast_noise、sin、cos、shift、cellular 节点；分别匹配单点与体积采样的 float / 截断规则，并导出 merged 包装器实际执行的 full 图。 |

修正后的快照使用独立的成品缓存身份，避免继续读取旧标签、旧末地路由或错误群系编号生成的结果；不要求手动删除整个缓存目录。没有新标签字段的旧快照仍可读取。

这些是对应接口、快照和算法的兼容结论，不等于任意整合包内所有模组的植被、结构和画面均已实机验收。TerraBlender 1.20.1 的当前发布没有末地扩展 API，该版本继续使用普通区域适配；末地扩展的实际 JAR 回放检查按不适用记录。

验证输入、构建身份与通过／跳过数量见[阶段验证记录](../history/validation.md)。这些修复属于 Fabric 目标，不能据此声明 Forge / NeoForge 同样完成适配。


## 26.3 Vulkan 预测计算与模组

GPU 加速接在远景预览与正式细化的密度／高度计算阶段，群系路由、表面规则、流体、颜色、结构和植被继续使用已有 Rust／Java 后端。正式细化使用区块体积插值规则，并搜索所有高度层，保留薄悬空地形。开启开关后保留同一份服务端生成快照、种子和模组参数。

已对照 NeoForge 项目的世界生成 codec 清单和专用适配入口；Fabric 的清单没有缺少其中已登记的 codec。各阶段的执行范围如下，具体模组是否提供对应 Minecraft／Fabric 发行版仍按其发布范围判断。

| NeoForge 已有适配范围 | Fabric 26.3 中的执行方式 |
| --- | --- |
| Tectonic，包括已应用的替代缩放预设 | GPU 接收服务端已生效的 scale、multiplier、offset、smoother 参数；保留单点与体积路径的不同运算顺序。 |
| Lithostitched | GPU 支持坐标偏移、细胞噪声及其特征点条件、Perlin、OpenSimplex2S、FBm／Ridged／PingPong、FastNoise 细胞噪声、三角函数和嵌套插值；不重新生成随机种子。 |
| TerraBlender、Blueprint 群系路由 | 保留原有快照和 Rust／Java 群系选择；密度图可使用 GPU，群系与表面结果仍由原后端生成。 |
| BetterEnd | 保留专用地形 API、采样网格和群系路由。采用自定义生成器的路径继续使用原兼容执行器；普通密度图中的末地岛噪声可导出 GPU。 |
| FreeTerraForged／ReTerraForged | 保留自定义生成器与 Rust 过滤器组合；旧 double 密度或专用噪声图继续使用现有后端，不强行按 26.3 float 图转换。 |
| Alex’s Caves、YoukaiHomecoming 的已知表面条件 | 表面条件继续由已有 Rust 实现处理；不将 NeoForge 独有发行版宣称为 Fabric 可安装模组。 |
| The Lost Cities 与通用结构／植被适配 | 保留结构提示、真实列及装饰流程。GPU 密度加速不替代这些阶段。 |

多个预测请求按同一世界和计算类型合并提交：最多接纳八个待完成请求，其中正式细化最多两个，单次最多 512 列；其他工作线程继续由 Rust 处理。已在原生缓存中的列不再提交 GPU。不等待凑满批次，不读取“GPU 使用率达到某百分比”来暂停计算。队列限制控制的是本模组的等待量；它不能保证显卡在光影或高分辨率渲染时仍有空余算力。

运行时先校验密度、完整预览记录与独立的正式细化高度边界，再按规则网格比较实际耗时；CPU 更快的图或密集采样间距保留 CPU 路径。超出已支持数值范围的计算会回到 Rust，不把无效 GPU 高度送入材质阶段。驱动管线缓存按显卡、驱动和计算程序隔离保存。实际游戏帧率和整合包画面仍需另外验证。
