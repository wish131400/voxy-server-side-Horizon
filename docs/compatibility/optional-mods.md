# Fabric 可选模组适配

[依赖与版本](README.md) · [世界生成适配](worldgen.md)

以下按真实 Fabric 发布包核对接口。模组不存在对应 Fabric 发行版，或某版本没有发布包时，不能从共享代码推导出已经支持。可选模组无需随 VSS 一起安装。

本表描述 2026-10-30 这一轮源码的适配与固定检查输入，统一验证仍在进行。当前八目标候选包标识仍为 `voxy-update-20261029`，尚未包含本表所述的本轮新增改动；最终验证与打包结果以[阶段记录](../history/validation.md)为准。

| 模组 | 固定审查输入 | 源码适配行为 |
| --- | --- | --- |
| Trinkets | 1.20.1 / 3.7.2；1.21.1 / 3.10.0 | 同步远玩家饰品、槽位属性与尺寸；使用完整同步属性替换旧状态，卸下或缩减槽位时清空残留。 |
| Accessories | 1.20.1 / 1.0.0-beta.49；1.21.1 / 1.1.0-beta.54 | 按原模组完整容器同步流程恢复功能饰品、装饰饰品和显示开关，并重建容器缓存。 |
| FTB Chunks | 1.20.1 / 2001.3.8；1.21.1 / 2101.1.22；1.21.11 / 2111.1.1；26.1.2 / 26.1.2.9 | 按服务器共享预算提交强加载请求；合并重复请求，取消时清除旧队列，保留 FTB 原有持久化和加载票据。 |
| FTB Essentials | 对应上列目标的 2001.2.4、2101.1.10、2111.1.1、26.1.2.5 | 保留原生随机传送的地形查询；撤销用平原与零高度替代未加载地形的旧补丁。没有新增异步随机传送。 |
| Oh The Trees You'll Grow | 1.20.1 / 1.7.3；1.21.1 / 5.3.5；1.21.11 / 9.1.2；26.1 / 10.0.4；26.1.2 / 10.1.4；26.2 / 11.0.4；26.3 / 12.0.3 | 预测树木访问已验证模板管理器；同时匹配旧 Fabric 生产方法名，避免开发环境正常而发布包挂钩未生效。 |
| ByePregen | 26.1.2 / 1.1.2.5；26.3 / 1.1.3.5 | 精确选择对应发布版的地形判断方法；26.3 使用独立参数适配，避免同名重载导致漏挂钩。 |
| Create Fabric | 1.20.1 / 6.0.8.1+build.1744 | 保留移动结构就绪检查与远玩家渲染桥；核对真实实体接口。 |
| FreeTerraForged / ReTerraForged | 1.21.1 / FreeTerraForged 1.0.0 与 ReTerraForged 0.0.6005 | 分别验证两种命名空间的生成接口、预设回放和原生过滤挂钩。这是替代关系，同一客户端只选择其中一个。 |
| The Lost Cities | 26.2 / 11.0.3；26.3 / 12.0.0 | 核对实际建筑、道路、调色板与结构资源接口，沿用对应版本的预测桥。 |
| Xaero's World Map | 1.20.1、1.21.1 / 1.47.0；其余六目标 / 1.47.2 的对应文件 | 核对真实地图写入、保存生命周期与纹理缓存接口；继续区分真实区块和预测区域。 |
| C2ME | 八个 Minecraft 目标各自固定的发布文件 | 兼容其密度函数缓存所有权，保留已编译求值器；仅对发布包实际包含的 DFC 模块执行专项检查。1.20.1 与 26.3 的固定输入没有该模块。 |
| Tectonic | 1.20.1 / 3.0.17；1.21.11 / 3.0.19；1.21.1、26.1、26.2 各自目标的 3.0.28；26.3 / 3.0.32 | 保存已应用的大陆与侵蚀噪声参数，支持启用替代缩放的 `I Use Voxy Btw` / `OVERKILL` 预设；Java 与 Rust 保持各目标真实求值精度，26.3 独立处理单点与体积路径。详见[世界生成适配](worldgen.md)。 |

Trinkets 与 Accessories 本轮只固定了 1.20.1、1.21.1 的发行文件，不能据此声明后续版本已经验证。FTB 的 26.1.2 文件依赖对应 Fabric API，不能作为 26.1、26.1.1、26.2 或 26.3 已验证的证据。

Blueprint 当前官方发行平台为 Forge / NeoForge；Create: Northstar 与 Northstar Redux 的已核对官方项目也没有 Fabric 发行文件。共享可选桥保留，但不把它们记为已完成 Fabric 实机适配。

Tectonic 上表只列出这一轮固定审查的实际文件，不把 26.1 的文件自动记作 26.1.1 / 26.1.2 已执行预设专项的证据。源码共用与实际依赖文件的目标声明分别核对。

验证工具使用固定来源与文件摘要；旧版 Fabric 发布包保留原始文件，并另行映射离线测试副本。接口存在、Mixin 实际应用和离线行为检查分别验证；提供了某个发布文件时必须实际执行对应检查，不能用无关用例的通过或未解释的跳过代替。八目标统一验证还需配合具体整合包的联网与画面验收。验证入口见 [构建文档](../development/build.md)。
