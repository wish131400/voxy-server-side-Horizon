# FreeTerraForged / ReTerraForged

[适配目录](README.md) · [世界生成适配](worldgen.md)

## 支持范围

本轮新增兼容针对 **Minecraft 1.21.1 Fabric** 的实际发行文件：

- FreeTerraForged 1.0.0。
- FreeTerraForged 测试版 1.0.0015、1.0.0016、1.0.0017、1.0.0018、1.0.0019、1.0.0020、1.0.0021、1.0.0022、1.0.0023。
- ReTerraForged 0.0.6005。

上游地址：<https://github.com/ETcodehome/FreeTerraForged/releases>。
这些模组互为替代，同一实例只安装其中一个。服务端与客户端的 VSS 需要一起更新，并使用匹配的上游地形模组。
本轮兼容声明不扩展到其他 FreeTerraForged 分支、Minecraft 版本或任意地形模组组合。

## 生成与缓存

旧版继续使用瓦片缓存与对应的 RandomState 初始化；新版使用上游的
TerraForgedChunkGenerator、生成 epoch 和编译计划，再读取 FilteredChunkCache。
服务端快照携带资源与标签版本、生成贡献版本，以及 1.0.0016–1.0.0023 的群系替换配置内容。
1.0.0015 使用不包含替换配置记录的早期接口。客户端本地配置不会覆盖服务端快照。

详细采样读取上游过滤后的精确单元，处理负坐标、区块与区域边界；粗预览保留上游快速估算，避免每个预览点生成完整过滤区域。
河流、湖泊、湿地的水面高度使用实际发行版的水文函数。优化气候采样器时保留生成计划、查询策略、完整种子、地表上下文与出生点查询状态，各采样器使用独立查询缓存。
来源采样器尚未初始化出生点查询时，保留目标已有状态；两边都为空时恢复 FTF 自身的世界原点默认值，避免向禁止空值的接口写入空值而中断预测初始化。来源已有用户指定坐标时按原值复制。

旧版 WorldFilters 可继续使用原有 Rust 挂钩。新版 TerrainFilters 保留上游 Java 算法，不套用旧版侵蚀过滤实现。
关闭预测只释放它自己持有的生成器、绑定和过滤缓存，不清理实时服务端生成器或关闭上游全局工作池。
缓存身份包含上游模组版本，避免不同发行版混用成品。

生成兼容代码放在 `mc121` 版本目录；其他 Minecraft 目标保留原有适配，不因此宣称能安装这些 1.21.1 发行包。

## 验证边界

离线验证使用实际 Fabric 发行 JAR，在独立 JVM 中检查真实预设与噪声注册表往返、
生成 epoch 与计划编译、RandomState 地形初始化、过滤单元、粗预览、水面、
气候上下文和缓存释放。旧版另外检查原生噪声数值、完整过滤结果及 Mixin 挂钩。
新版检查旧挂钩不会进入 TerrainFilters。

测试环境重放上游声明的生成器访问扩展，并为普通 JUnit 缺少的部分 Mixin 接口绑定提供代理。
1.0.0015–1.0.0023 另在独立测试 JVM 中真正应用发行包的气候 Mixin，执行出生点为空、用户坐标复制、已有目标保留以及气候策略、完整种子和独立缓存回归。
这不等于已经在完整客户端执行所有上游 Mixin。实际整合包、预设、光影、连续移动与再次进入世界仍需实机验收。
本轮不承诺具体加载速度或帧率提升，也不逐方块复现上游完整地表后处理中所有瀑布、河岸与邻列编辑。

显式内存群系计划无法通过普通来源 codec 完整恢复，客户端与服务端生成贡献不一致时也会拒绝重建，避免显示错误预测。
