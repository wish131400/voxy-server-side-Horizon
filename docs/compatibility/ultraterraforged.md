# UltraTerraForged 兼容

本轮适配固定到 [UltraTerraForged](https://github.com/Pandaismyname1/ultraterraforged) 的 `1.0.3` 发布文件，处理 [VSS Issue #8](https://github.com/wish131400/voxy-server-side-forge/issues/8) 中预测初始化失败的问题。

## 对应版本

| Minecraft | 本地 VSS 平台 | 验证输入 |
| --- | --- | --- |
| 1.20.1 | Forge、Fabric | 各自的 UTF `1.0.3+1.20.1` 发布文件 |
| 1.21.1 | NeoForge、Fabric | 各自的 UTF `1.0.3+1.21.1` 发布文件 |
| 26.1.2 | Fabric | UTF `1.0.3+26.1.2` Fabric 发布文件 |
| 26.2 | Fabric | UTF `1.0.3+26.2` Fabric 发布文件 |
| 26.3 | Fabric | UTF `1.0.3+26.3` Fabric 发布文件 |

Fabric 1.21.11、26.1、26.1.1 同步共享适配代码并做构建回归；未找到对应独立 UTF 发布文件，不能据此宣称这些组合已通过真实依赖验证。本轮没有新增 NeoForge 26.x 移植。

## 运行方式

服务端将活动 UTF 预设、噪声及存在的结构规则注册表纳入世界生成快照，携带明确的变体命名空间和发布版本。客户端先初始化 UTF 的 RandomState，再开始采样，避免 CellSampler 在上下文尚不存在时缓存空值。

表面规则的临时区块绑定实际采样位置，使 UTF 的高度、坡度和地表材质条件读取对应区块，避免始终读取原点区块造成灰白条带。规则上下文在当前任务内按区块有限复用，任务完成后释放；复用时读取当前地形输入。

精细地形读取 UTF 自身完成侵蚀、平滑及水岸处理后的瓦片，使用 `CellField.read(Cell)`。UTF 不需要旧 FTF 的 `WorldLookup.getHeightmap()`，也不会把初始化线程的可变高度图交给其他线程。26.3 使用对应的密度编译接口和 MaterialRule 表面规则接口，按实际 DensityVolume 位置绑定上下文。

UTF 保留自身的完整 Java 地形滤波，不接入为旧 FTF 数据布局编写的 Rust 滤波桥。现有其他生成器的 Rust 路径继续按各自的能力选择。高处河流、湖泊和湿地读取 UTF 的绝对 `waterLevel`，按其 RaisedWater 规则转换为水面顶面坐标。

Fabric 1.21.1 的外形批处理识别 UTF 的水平密度函数，复用相邻柱的插值和查询结果。VSS 拥有的 UTF 生成器在已获准执行的预测工作线程上完成内部批次，保留完整侵蚀、平滑和水岸滤波，避免嵌套启动额外的生成线程。UTF 真实区块生成仍使用原调度方式。缓存写锁内只登记原来的待完成条目，批次在登记返回、锁释放后执行，避免完整地形计算阻塞缓存命中读取。

粗预览的地表条件复用已有滤波瓦片；瓦片缺失时，调用 UTF 自身不加载瓦片的点采样接口，不再因创建地表规则启动完整侵蚀任务。NearGround 高度范围和各类地形条件仍使用 UTF 原判断。26.3 的延迟材质读取器由独立适配入口处理，精确细化及真实区块生成继续使用原完整结果。

此修复更新 FTF 家族预测缓存身份，旧版错误材质的预测数据会重新计算；首次进入可能需要重新铺开远景，无需手动删除世界数据。

退出预测时仅关闭当前上下文的瓦片缓存，不访问 UTF 已移除的全局缓存表，也不停止新世界的缓存轮询。

## 验证边界

验证包括真实发布代码的预设/噪声往返、初始化、生产线程钩子的实际应用、原异步批次与预测批次的滤波结果对照、完整密度图的外形采样对照、水位、气候出生点上下文和独立世界的缓存生命周期，以及跨区块表面规则、输入复用、任务释放、缓存身份、VSS 注册表快照与原有模块回归。

这些是构建和离线运行验证，没有代替完整整合包启动、联机、持续移动及最终画面验收。UTF 与其他地形模组叠加仍需按具体组合检查；流动水、河岸补块等原生区块后处理不保证逐方块复现，收到的真实区块继续由 Voxy 覆盖。

## 变体表与扩展接口

`FreeTerraForgedVariant` 是内部已验证的接口能力表，集中记录命名空间、包名、初始化方式、字段读取及滤波兼容性。加入一项仍需提供相应的语义适配和测试，填写包名本身不能保证兼容。

第三方模组可复用现有 `TerrainSnapshots.register(TerrainSnapshotProvider)` 服务端快照扩展点；需要自定义客户端采样时，使用现有 `PredictionTerrainBackends` 扩展。服务端参数投影、客户端采样器、缓存身份及资源释放应形成完整契约。本轮没有另行提供任意包名配置入口。
