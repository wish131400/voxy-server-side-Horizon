# 密度与地表高度搜索优化（2026-10-31）

[历史目录](README.md) · [问题定位与隔离实验](modern-density-audit-20261031.md)

构建标识 `20261031-density-surface`，版本号保持 0.3.7。针对 26.3 的生成核心实现三项优化，八个 Fabric 目标同步同一套原生库。

## 实现

1. **补齐末地有限范围。** 外岛节点的输出为 `[-0.84375, 0.5625]`；包装后的 i32 坐标差对应的四种距离度量也具有有限上界。两个范围共同传播后，中央岛与外岛的组合不再保持未知范围，插值格点可以继续使用原有两角点路径。没有改变噪声、岛屿公式或 FP32 算术。
2. **把地表证明范围与逻辑工作区分开。** 从最终密度实际依赖的插值节点计算横向网格公约数，并限制为 16 格工作区的约数。末地可复用完整 8×8 范围的空域证明，不再按逻辑 4×4 尺寸拆散；原有精确生成工作区仍为 4×8，体积边界、角点缓存和插值顺序保持原语义。嵌套及模组网格按共同边界处理，无关根节点不影响范围。
3. **专门编译两种噪声采样。** 在 octave 循环入口选择单点或体积模式，内部使用 Rust 常量泛型生成两个计算分支。省去梯度内的模式判断，让编译器看到确定的算术顺序；保留单点的 X/Y/Z 与体积的 X/Z/Y 梯度累加顺序、FP64 坐标和折返，以及 FP32 插值和 octave 累加。未使用 fast-math、重排运算或降低地形质量。

## 收益测量

基线为已发布的 `20261031-refinement-grid`，不把上一轮的收益重复计入。使用相同的实际版本世界生成文档、JDK 25、固定群系和共用方块属性，每个候选运行于独立 JVM；每组 16 个工作区、1,024 个冷列，九轮取中位数。部分缓存组每窗口缺少 48 点。创建后端不计入列查询耗时。计时期间没有并行构建或测试。

候选库主世界间距 4 从 88.056 ms 降至 68.139 ms；间距 16 从 98.978 ms 降至 81.406 ms。负种子、负坐标并颠倒候选运行顺序后，间距 4 从 85.190 ms 降至 68.618 ms，间距 16 从 97.341 ms 降至 79.841 ms。单独的噪声专门化相对仅补范围和横向网格的候选仍有稳定收益。

末地间距 4 从 35.128 ms 降至 24.411 ms；间距 16 从 174.938 ms 降至 39.664 ms。负坐标复测分别从 36.583 ms 降至 25.381 ms、179.842 ms 降至 41.709 ms。下界判断与横向复用对不同 LOD 档位的贡献不同，不能把最高百分比套用到所有场景。

主世界部分缓存间距 4 从 64.478 ms 降至 51.906 ms，约下降 19.5%。下界间距 4 从 11.188 ms 降至 10.646 ms，仅约下降 4.8%，不是所有维度都出现同等收益。

## 继续优化的优先级

- **值得后续测量：** 专门编译最终密度的热点子图；按相同插值网格和体积上下文批量处理坐标，复用层级中间值。先测分支、查表与内存成本，再决定是否增加缓存。
- **暂不合入：** 上轮独立端点缓存和符号快捷路径只有约 0%–3% 的收益，当前没有足够理由再增加常驻状态与维护分支。
- **不直接使用：** 对任意地形整柱二分、根据相邻高度直接截断搜索、将密度当距离场大步行进。悬空岛、山脊、洞顶和薄层会使这些假设失效；需要有适用范围证明后才能作为局部路径。

## 验证范围

新增检查覆盖四种距离度量的整数极值与包装减法、实际末地输入的有限范围、独立地表证明宽度、无关根节点、嵌套网格、横向倾斜表面以及正负远坐标。保留原版 26.3 单点与体积逐位样本、Tectonic 与 Lithostitched、薄层和非有限值回退检查。

最终 Rust 核心检查 83 项通过、4 项外部或计时诊断跳过；显示检查 15 项、现代图缓存与地表搜索对照各 1 项通过，共 100 项通过。最终 Windows 资源库在八个版本、三个维度、普通采样四档和部分缓存网格两档的 144 组对照中，完整输出校验值全部一致；跨版本对照只作为一致性检查，其运行时间不用于上表收益。

五平台原生库完成交叉编译。最终资源库在 RTX 4070 Ti SUPER 上通过全部 5 项 Vulkan 检查，覆盖原版与模组节点、嵌套体积、正式显示区域、薄层及 CPU 回退；GPU 密度浮点数按既有误差标准比较，不能与 CPU 前后逐位一致性混为一谈。八目标包的源码摘要、原生库与构建标识见本次发布清单；Linux/macOS 运行和实际游玩 FPS 不能由离线对照代替。
