# Sodium 配置页兼容（2026-11-02）

本轮为当前维护的 Fabric 目标补齐 Sodium 0.5.13 起的配置入口。Sodium 0.5 使用 `me.jellysquid`，0.6 / 0.7 的旧选项模型使用 `net.caffeinemc`；0.8 / 0.9 使用配置注册 API。游戏版本、Voxy 和 Iris 仍须按各自依赖组合安装，配置页适配不改变第三方模组的依赖要求。

## 修复

- 统一选择旧选项模型的命名空间，页面、控件、存储和格式化器使用同一接口族。
- 旧 Sodium 通过 `createScreen(parent)` 创建屏幕，保留其损坏配置恢复入口。VSS 只设置初始选中页，等屏幕正常初始化后再创建控件，避免提前 `setPage` 触发字体为空。
- 直接在旧 Sodium 的屏幕构造完成时添加 VSS 同步页和预测页，不要求另装 Options API。第三方入口与 VSS 直接入口重复触发时复用现有页。
- 保持同步页、预测页的顺序；0.8 / 0.9 继续通过原生注册接口接入。
- 可选挂钩只检查目标屏幕字节码，不在 Mixin 准备阶段提前加载 Sodium UI。

## 验证方法

`tools/verification/sodium-options.gradle` 使用实际 Sodium 发行包构造生产选项树，修改并应用开关、调用存储回调，再读取实际保存文件；旧接口另外使用真正的 Sponge transformer 验证构造挂钩。Sodium 仍是可选依赖，测试依赖不会进入发布包。

客户端探针分别验证普通视频设置与 VSS 直接入口，初始化页面并切换到预测页。此验证不进入世界，不代表光影或整合包游玩验证。首轮真实客户端验证复现了提前 `setPage` 的空字体错误，修复后相同探针通过。

当前验证记录与完整矩阵以本轮交付结果为准。0.7.3 的发行包来自 Minecraft 1.21.10，仅作为同族接口核对；本项目没有新增 Minecraft 1.21.10 目标，也不声称完成该游戏版本的启动验证。

真实开发客户端已验证 1.20.1 + Sodium 0.5.13 + 社区 Voxy 0.2.15-beta，以及 26.3 + Sodium 0.9.3-beta.1 的两个配置入口与预测页初始化。26.3 的此项通过记录使用纯 Sodium / VSS；加入所选 Voxy 0.2.20-beta 后，开发启动因该 Voxy 的 `MixinConfig.getRefMapperConfig()` 接口错误失败，不能将纯配置页验证扩展为该 Voxy 组合启动通过。

以上以各 Minecraft 版本配套的 Sodium 发行包为边界；没有把某个游戏版本的 Sodium 文件强制用于其他 Minecraft 版本，也没有逐一运行所有历史补丁版。

表中共 11 个游戏与 Sodium 组合，每组合执行页面行为与接口挂钩两项，共 22 项通过，无失败或跳过。新注册模型的接口检查确认使用原生入口，并确认旧屏幕挂钩不适用；不将其计作旧屏幕 Mixin 转换。

## 正式客户端检查

使用最终的 `vss-0.3.7-fabric-1.20.1.jar`、未修改的 Sodium 0.5.13 和社区 Voxy 0.2.15-beta，在独立的普通生产运行环境中启动通过。探针核对了普通视频设置入口自动含两个 VSS 页面、VSS 直接入口、预测页控件初始化及页面去重，进程正常退出；被检查 JAR 的校验值与根目录交付包相同。此项未安装 Iris，也未进入世界，不代表完整整合包、光影或实际游玩画面验证。

该生产运行使用 Fabric Loader 0.20.1；另外的开发客户端入口检查使用对应目标的编译依赖基线。测试探针和 Sodium 依赖均不打入 VSS 生产 JAR。

## 成品

八个 Fabric 目标均已从同一冻结源码构建，构建标识为 `20261102-sodium-options`。最终构建阶段共 277 项缓存与配置页回归通过，无失败、错误或跳过；此数量包含重跑的 Sodium 检查，不能与上表 22 项直接相加作为独立用例数。1.20.1 与 26.3 另外覆盖低核缓存恢复路径。

成品包含本轮配置页修复、缓存独立探测与恢复并发改动，以及 Fabric 1.21.1 的 FreeTerraForged 出生点状态修复。标准 JAR、`vss-0.3.7.zip`、清单、源码摘要与 SHA256 均在项目 `lib` 根目录。
