## Fabric 实现

`Graph::compute` 在入口按图格式选择 `compute_typed::<true/false>`，旧节点递归和现代节点调用直接进入对应实例。图格式在构造后不变，编译器可以移除另一种格式的分支。保留浮点精度、累加与插值顺序、缓存键、结构贡献和体积上下文，不增加线程或运行设置。

前轮隔离构建观察到现代公共调度实例静态栈分配从 600 降至 104 字节，旧版为 568 字节；这不代表完整查询的栈峰值或游戏内存降幅。正式交付单独以生产构建的配对耗时判断收益，没有把候选库的最佳数字当成正式结果。

## Forge / NeoForge 适用性

| 前轮或本轮方法 | 旧版内核的处理 |
| --- | --- |
| 通用噪声内联、SSE4.1 精确取整 | 前轮已同步，保留现有实现 |
| 单柱插值边复用、地表高度计划 | 原有实现已经存在，核对后不重复添加 |
| 有限选择分支范围合并 | 本轮同步到 `Node::Select`，覆盖现有 Lithostitched 选择节点；所有结果分支有限才使用范围 |
| 共享图的符号计划总展开预算 | 本轮同步，最多展开 128 次，其余节点保留精确求值叶子；不限制真实地形图、任务数或 LOD 工作量 |
| 本次双格式求值特化 | 旧内核只有 FP64 图，没有第二种格式分支，不套入该结构 |
| 26.3 FP32 八角 AVX2、体积角点数组、现代符号计划 | 语义属于现代图，旧内核保留原有算法 |

旧版另行实验的常量提前返回没有稳定收益，未合入。旧末地整数包装后可能产生非有限值，不能套用现代末地的全局有限范围。旧版库没有被整个 Fabric 目录覆盖。

旧版有限选择节点受控输入的最终库，间距 4 从 71.462 降至 46.911 ms，间距 16 从 164.254 降至 57.556 ms。它是为分支路径构造的 Lithostitched 输入，不是完整模组世界，更不能换算为所有世界的提速比例；两旧仓库各自记录完整结果。

## 验证与交付

- Fabric 生产源码 Rust 检查 128 项通过，4 项原有外部／计时诊断保持忽略；包含库、显示、现代缓存／地表、原版噪声与世界生成、Lithostitched Java 参考。
- 旧版同一候选源码 72 项 Rust 检查通过，4 项原有诊断忽略；新增有限选择、非有限分支回退和共享 DAG 预算检查。两个生产源码树逐文件匹配通过检查的候选。
- 旧版最终生产 DLL 覆盖 1.20.1、1.21.1 三维度和受控选择输入，28 个配置的完整记录一致；受控选择另通过 19 轮反序确认。
- 两套核心分别交叉构建 Windows x86_64、Linux x86_64 / ARM64、macOS x86_64 / ARM64；旧版两项目源码和五库 SHA 一致。
- 最终 Fabric 资源 DLL 在 RTX 4070 Ti SUPER 通过 5 项 Vulkan 检查，无失败或跳过；这是正确性验证，验证时的吞吐打印未用作本轮性能结论。
- 原生包检查分别核对 Fabric 的 48 个、旧版核心的 42 个 JNI 导出，以及架构、glibc 2.28 上限、macOS 11.0 下限和 ARM macOS 签名；源码快照、构建标识与 SHA 由发布工具检查。
- 本轮没有测游戏 FPS、完整模组世界、Linux/macOS 运行或 ARM 真机性能。CPU/JNI 地形耗时不包含 Java 植被、磁盘、调度、GPU 或 Voxy 发布和渲染。

Fabric 根 `lib` 更新八目标标准 JAR 和 `vss-0.3.7.zip`；NeoForge / Forge 更新各自标准 JAR，并将同一个双版本 ZIP 写入两根 `lib`。旧包在构建前备份，保留标准文件名。原始矩阵、日志、源码验证快照与备份位于忽略的本轮实验目录，不提交机器采样和构建产物。
