# 26.3 噪声角点并行优化（2026-10-31）

[历史目录](README.md) · [上一轮核心同步](native-sync-20261031.md)

本轮基于 `20261031-native-sync` 继续审查 26.3。确认有稳定收益的是现代噪声的四角 SSE4.1、八角 AVX2 梯度计算，已合入 Fabric 主源码。其他候选留在隔离实验目录。构建标识为 `20261031-modern-simd`，版本仍为 0.3.7。

状态：数值回归、五平台原生构建、正式 Windows 库对照和八目标标准 JAR 验证已完成，合包记录见发布清单。

## 改动及原因

位置：`tools/rust/vss-native-core/src/noise/modern.rs`。

上一轮 SSE4.1 路径已将取整替换为 CPU 指令，但八个梯度仍通过数组构造辅助函数计算。仅将整个函数标记为 AVX2 没有稳定提速；编译器并未自动生成这次需要的八角点并行计算。

本轮显式并行计算同一噪声点的梯度：

- 支持 AVX2 时，一次计算八个角点；支持 SSE4.1 时分两组，每组四个角点；其余 CPU 使用原通用路径。
- 用寄存器内的梯度表查找，保持每个角点原来的乘法和加法顺序。体积模式保留 X、Z、Y 的加法顺序，标量模式保留 X、Y、Z。
- 坐标、置换表和随机流保持原样；没有启用 FMA 或 fast-math，没有改变 octave 的累加顺序。
- 自动按运行时 CPU 能力选择路径，不增加设置、不分配新的常驻缓存。
- ARM64 保留通用实现。本轮没有新增 NEON 路径，也没有 ARM 真机收益数据。

这里是同一个噪声点的角点并行，不是同时生成八个地形列。优化发生在现代原版噪声叶节点；Tectonic 等复用这些叶节点的图可继续使用，Lithostitched 的独立 FastNoise 等实现保持原路径。不能把原版收益直接套给所有模组组合。

## 正式库实测

CPU 为 Ryzen 7 7700，Windows x86_64、JDK 25。使用真实版本世界生成快照、固定群系和共用方块属性，每组单独 JVM，串行运行 11 轮取中位数。常规组为 1,024 列；部分缓存组为 768 列。基线是上一轮已发布 Windows 库，SHA256 为 `b159750a2454f405124d293da336f7a53c5ccf6811f624b35ecce1c692ed47df`。

| 主世界 | 1 | 10.489 | 9.227 | 12.0% |
| 主世界 | 4 | 56.943 | 48.679 | 14.5% |

主世界间距 4 的反序复测为 `56.804 → 49.809 ms`，下降 12.3%；负坐标、种子 -917 为 `57.306 → 48.852 ms`，下降 14.8%。下界间距 1 为 `5.838 → 5.833 ms`，几乎没有收益。SSE4.1 四角候选在两次主世界间距 4 对照中省约 6%–9%，最终入口在本机选择 AVX2。

同批次未修改算法的版本对照，主世界间距 4 为：Fabric 1.21.1 `45.681 ms`，26.2 `47.210 ms`，26.3 正序和反序为 `48.679–49.809 ms`。因此本次场景中 26.3 距 1.21.1 约多 7%–9%，距 26.2 约多 3%–6%；这只是该输入的核心计算差距，不是所有地形或游戏加载速度的固定比例。

计时包括 CPU/JNI 显示地形计算，不包含 Java 植被、磁盘、任务调度、GPU 计算、Voxy 发布和渲染。不同间距固定请求列数，覆盖的区块不同，不能把单组毫秒数解释为整层 LOD 用时，或直接换算成 FPS。

## 排除的候选

| 候选 | 决定 |
| --- | --- |
| 仅增加 AVX2 编译路径 | 主世界收益不稳定，未单独合入 |
| 将 smear 模式判断移出 octave 循环 | 主世界反而略慢，未合入 |
| 预计算 Y=0 的噪声平面及部分置换表 | 增加每层约 520 字节，主世界没有稳定收益，未合入 |
| 常见网格步长用位运算代替除法／取余 | 各间距有涨有跌，未合入 |
| 保存固定 X/Z 插值列的 Y 结果 | 个别组略快，部分缓存与大间距没有稳定收益，未合入 |

这些候选没有进入生产缓存或调度逻辑。插桩诊断也表明，当前核心主要工作仍在密度、噪声和材质查询，分组及工作区准备只占很少时间。插桩本身有取时开销，其耗时不能当成正式库的精确占比。

## 验证

- 91 项 Rust 库检查通过，4 项外部输入／计时诊断保持忽略；15 项显示地形和 2 项现代缓存／地表搜索检查通过。
- 现代噪声的 60,432 个坐标与模式样本逐位比较通用、SSE4.1、AVX2 和运行时入口，覆盖不同种子、周期边界、负坐标、取整边界和 smear。
- 梯度检查覆盖全部 256 种置换值及每个向量通道，包含正负零、次正规数和单元边界，核对原标量梯度运算的结果位。
- 原版三维度、Tectonic 语义和 Lithostitched 参考、嵌套插值、结构密度变化、重置及范围证明检查通过；70,800 次现代编译图与未折叠递归对照保持逐位一致。
- 最终生产 Windows 库完成 8 组配对、30 组采样间距的完整十字段输出核对，包含三维度、部分缓存、负坐标和反序，以及 1.21.1、26.2 的未修改路径对照。
- 最终资源库通过 5 项 Vulkan 正确性检查，覆盖原版／模组、标量／体积和显示地形；包内五库通过架构、48 个 JNI 导出、glibc 2.28 上限、macOS 11.0 下限和 ARM macOS 签名检查。
- 五平台完成交叉构建。Linux/macOS 运行、缺少 AVX2 的真实 CPU、ARM 性能和游戏 FPS 尚未验证；SSE4.1 与通用入口是在本机直接调用比较的。

原始 JSON、隔离副本、汇编摘录、构建日志和旧标准包备份位于忽略的 `external/performance/20261031-modern-next/`。生产 Rust 相对本轮起点只修改 `src/noise/modern.rs`；相邻 Forge、NeoForge 核心未修改。
