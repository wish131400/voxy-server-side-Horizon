# 26.3 地表符号判断优化（2026-10-31）

[历史目录](README.md) · [上一轮噪声并行](modern-simd-20261031.md)

本轮基于已发布的 `20261031-modern-simd`，继续减少 26.3 地表高度搜索中的密度范围运算。版本保持 0.3.7，构建标识为 `20261031-modern-sign`。修改限于独立 Fabric 仓库，未修改相邻 Forge、NeoForge 的源码和包。

## 原因和改动

地表搜索需要证明一段高度内最终密度是否始终为正或非正。旧版密度已编译专门的符号计划，26.3 的现代节点此前整体作为叶节点，反复进入通用范围求值。现代范围求值本来就有 Min 的负区间短路；本轮将外层的零结构贡献、Min 和 Squeeze 也纳入现有符号计划，减少通用包装的遍历、浮点范围变换与保守范围扩张。

- 结构密度贡献为零时，直接判断地形子树；存在非零结构贡献时继续使用原 Add 范围求值。
- Min 的两个子树均有有限全局范围时，分别证明符号，允许在结果已确定时结束判断。含 NaN 风险或范围未知的子树继续使用原求值器。
- Squeeze 复用保守的正值余量传递，避免只为判断符号重复计算上下界变换。极小值不够形成证明时，继续精确求值。
- 计划编译最多展开 128 个节点，达到预算的分支保留原叶节点。该限制只约束优化计划，不拒绝数据包或限制实际地形计算，避免共享密度 DAG 展开成指数大小的树。
- 精确密度、噪声、材质、结构与插值运算保持原实现。不增加工作区缓存、线程和设置，不改变 LOD 采样间距。

生产实现为 `tools/rust/vss-native-core/src/density/surface_plan.rs`，专项回归为同目录的 `surface_sign_tests.rs`。

## 隔离复测

多次串行对照中，主世界间距 4 通常从约 49–50 ms 降到 46–47 ms。只透传零结构贡献也有小幅收益；完整符号计划更稳定。将该计划进一步用于边界单点、改变 memo 体积键、用全局上下界跳过 Min/Max、直接扫描短高度区间均没有稳定的额外收益，未合入。直接扫描短区间在主世界明显变慢，原有范围证明仍有必要。

主世界间距 4 的反序复测为 `49.260 → 46.875 ms`，下降 4.8%；种子 -917、负坐标为 `49.216 → 46.963 ms`，下降 4.6%。中远间距正序、反序和负坐标的降幅约 3%–5.5%。间距 1 在主组几乎持平，其他复测略快。

下界没有稳定收益：第一次间距 4／64 多约 0.058／0.276 ms；19 轮反序复测分别为 `8.419 → 8.550 ms`、`9.313 → 9.475 ms`，测得小幅回退。因此本轮主要收益在主世界中远层和部分缓存细化，不代表所有维度均会提速。末地间距 4 首次略慢，较大间距有小幅收益。

同批次主世界间距 4：Fabric 1.21.1 为 `46.496 ms`，26.2 为 `48.248 ms`，26.3 为 `46.875–47.653 ms`。在这个输入上，26.3 已接近 1.21.1 的核心计算时间。未修改的 1.21.1／26.2 路径对照的输出一致，用时变化约在 1.5% 内。

计时只覆盖 CPU/JNI 显示地形，不含 Java 植被、任务排队、磁盘、GPU、Voxy 发布及渲染。不同间距固定请求列数、覆盖区域不同；毫秒数不是整层 LOD 加载时间，也不能直接换算 FPS。模组图继续使用原兼容路径，收益取决于其具体结构。
