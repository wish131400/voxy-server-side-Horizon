## 当前可选模组与 Tectonic 构建

2026-10-30 的八目标候选构建标识为 `fabric-optional-20261030`，包含本轮可选模组适配和 Tectonic 预设修复。八个标准 JAR 使用同一份生产源码，SHA-256 为 `3b724bccaab22db2f06e7ef09573b198e351cdad428b8d7a04b44dfe1ce412d9`。`lib/vss-0.3.6.zip` 按目标分目录，`lib/manifest.json` 与 `lib/SHA256SUMS.txt` 记录构建、源码和文件身份；旧包留存在 `lib/archives`。

本轮补充 Trinkets / Accessories 完整饰品状态同步、FTB Chunks 强加载队列与取消清理、实际树木模板管理器及 ByePregen 版本参数适配；FTB Essentials 保留真实地形查询，移除伪造平原和零高度的旧替代。另对 Create、Xaero、C2ME、FreeTerraForged / ReTerraForged 与 The Lost Cities 增加固定实际发布包的接口或挂钩检查。具体输入范围见[可选模组适配](../compatibility/optional-mods.md)。

Tectonic 的 `I Use Voxy Btw` / `OVERKILL` 预设会启用替代大陆或侵蚀缩放。审查发现，旧版 `ConfigNoise` 遍历可能跳过访问器自身，而来源 codec 只保留配置键和输入、遗漏已经应用的缩放、倍数、偏移和 smoother 标志，导致快照失败或重建后参数不一致。源码改为捕获实际执行参数并恢复嵌套图，Java 与 Rust 均增加对应求值节点。26.3 单独保留真实发布实现的 float 精度和单点／体积求值顺序，包括该发布版 smooth 体积路径省略偏移的行为。

基于 `98b005f` 的[八目标与六社区 GitHub 验证](https://github.com/wish131400/voxy-server-side-Horizon/actions/runs/40980099479)全部成功。按任务原始 XML 去掉验证目录中的复制件后，八目标模块、迁移和 Voxy / Iris 接口共执行 5,026 次检查，4,976 次通过、50 次显式基准、外部输入缺席或不适用检查跳过。可选依赖按九轮独立执行计算，共 833 次、758 次通过、75 次明确跳过，零失败；1.21.1 的 FreeTerraForged 与旧 ReTerraForged 分开执行，两轮各 93 次、89 次通过、4 次因其他可选输入缺席而跳过。合计 5,859 次执行、5,734 次通过、125 次跳过，没有失败或错误；这些是跨目标与任务的执行次数，不是独立逻辑用例数。

本地使用与安装包一致的 Windows x64 原生库，八目标 Tectonic JNI 专项共 10 次全部通过，包括实际预设、极值种子和边界坐标的逐位结果；26.3 另检查真实噪声种子别名及发行包当前使用的倒数节点。Rust 发布模式库回归 63 项通过、4 项外部输入或基准检查未启用。[五平台原生库构建](https://github.com/wish131400/voxy-server-side-Horizon/actions/runs/40976599358)全部成功，原生源码摘要为 `eb0594b8324d54de61fd0fcd24a970a8749faf74a75a2da2710244ed8ae51633`，最终各 JAR 的五份库均核对构建清单与文件摘要。

## 上一批调度与地图构建

上一批八目标候选包的构建标识为 `voxy-update-20261029`，当时均通过生产构建和包内源码、版本与原生库校验，生产源码 SHA-256 为 `f9135b29a891076b0bcbd6bb4baba9bf957462eb50c3120440b79d21bd1bc2dc`。该批产物与校验值留存在 `lib/archives/voxy-update-20261029`。

该批合包按 Minecraft 版本分目录收纳构建，附带构建清单和源码摘要，只包含本仓库的 Fabric 版本。

本批新增后台 Voxy 更新通知与旧区域清理、缓存两阶段启动、内容复用、低内存任务额度交接、单人独立生成额度，以及相同版本真实区块的 Xaero 补写与重试。四个代表目标的性能回归共执行 1,520 次，全部通过；随后新增配置与地图组合在 1.20.1、1.21.1、26.1.1、26.3 分别通过 141、141、147、147 次检查，取消首次导入的地图背压后又完成受影响路径补验。八个最终 JAR 均已核对源码快照、版本、构建身份与五平台原生库。上述数量包含不同任务间的重复执行，不是独立用例数；尚未安装这批新包复测实际帧时间、传送等待与地图补齐。

## 旧版与社区适配阶段

> 本节对应世界生成修复之前的阶段构建，包括 `fabric-6a43e0bb24e8`；其中“本轮”“最终构建”均指当时那一轮。当前构建的复验范围以上节为准。

当前定位为候选移植版。编译、离线回归、真实依赖接口检查、GPU 合同和启动检查分别验收；标题画面初始化不代表实际游戏内地形和光影已经验收。实际游玩、长距离移动、传送、预测切换、重新进入世界及具体光影包的画面与帧时间仍需实机确认。

新增的 1.20.1 和 1.21.1 已完成生产编译、网络与模块回归、世界生成迁移、真实 Voxy / Iris 接口及 GPU 检查。两版专用服务器均完成启动、真实列预生成、缓存保存与正常退出；客户端完成标题初始化，并实际调用生产预测代码验证材质图集读取。1.20.1 的专用服务器使用 Java 17，配套社区 Voxy 的客户端使用 Java 21。测试中需显式启用的分配微基准、未提供的历史 Voxy 或可选世界生成模组输入，均单独记录为跳过。

本轮还同步了下午的 Voxy 根节点 / 遍历队列容量修复，并修复客户端世界生成快照缺少静态注册表、要塞首选生物群系标签未展开的问题。六个现代目标的完整原版植被和结构快照往返共 38 项针对回归通过；旧两版也使用实际网络注册表执行对应回归。植被与最终体素使用新的缓存身份，更新后会重新生成旧的空植被结果，已有原始地形采样仍可复用。
