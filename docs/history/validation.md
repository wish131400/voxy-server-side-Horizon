## FreeTerraForged 1.21.1 Fabric 出生点上下文修复（2026-11-02）

本轮补齐 `mc121` 的出生点查询复制：来源存在时精确复制，来源缺失时保留目标已有状态，两边都缺失时恢复 FTF 自身的世界原点默认值。继续保留生成计划、气候策略、完整种子、地表上下文和独立查询缓存，避免空值导致预测初始化中断。

使用实际 Fabric 发行 JAR 检查 FreeTerraForged 1.0.0、1.0.0015–1.0.0023 和 ReTerraForged 0.0.6005，共 11 个文件、92 次执行，零失败、错误或跳过。每版检查运行时适配、服务端快照与过滤挂钩；两个旧版还执行原生噪声与过滤回归。九个新版分别在独立 JVM 中真正应用上游气候 Mixin，验证出生点缺失、用户坐标、已有目标保留，以及气候策略、完整种子和独立缓存。

发行文件为 Fabric intermediary 命名，测试使用有校验记录的 named 副本；原始发行文件保持不变，测试副本不随模组分发。生成器继承规则按上游 access widener 在测试类路径重放，其余非本轮目标的 Mixin 接口仍由既有离线夹具绑定。本轮没有在用户完整整合包中重进世界或验收画面，也不以这些离线检查宣称实机加载速度。

八个 Fabric 目标全部重新构建，通过构建标识、当前源码摘要、目标接口、关键兼容字节码与五平台原生库校验；构建期间与结束后核对源码快照一致。标准 JAR 和八目标合包更新到本仓库 `lib` 根目录，清单、源码快照及校验表同步更新，旧包备份保留。
