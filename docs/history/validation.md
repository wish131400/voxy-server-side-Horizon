按构建和输入记录验证范围。下面的旧阶段结果保留原始证据，不自动计作当前构建复验；GPU 小场景、标题初始化、自动世界流程与人工游玩分别验收。

## 尚未打包的源码改动

2026-10-30 的可选模组适配与 Tectonic 预设修复仍在源码验证阶段，未包含在下面 `voxy-update-20261029` 的八目标候选包中。构建与回归完成后另行记录最终源码身份、产物摘要及结果；不能把历史通过数量计作这些改动的复验。

本轮源码补充 Trinkets / Accessories 完整饰品状态同步、FTB Chunks 强加载队列与取消清理、实际树木模板管理器及 ByePregen 版本参数适配；FTB Essentials 保留真实地形查询，移除伪造平原和零高度的旧替代。另对 Create、Xaero、C2ME、FreeTerraForged / ReTerraForged 与 The Lost Cities 增加固定实际发布包的接口或挂钩检查。具体输入范围见[可选模组适配](../compatibility/optional-mods.md)。

Tectonic 的 `I Use Voxy Btw` / `OVERKILL` 预设会启用替代大陆或侵蚀缩放。审查发现，旧版 `ConfigNoise` 遍历可能跳过访问器自身，而来源 codec 只保留配置键和输入、遗漏已经应用的缩放、倍数、偏移和 smoother 标志，导致快照失败或重建后参数不一致。源码改为捕获实际执行参数并恢复嵌套图，Java 与 Rust 均增加对应求值节点。26.3 单独保留真实发布实现的 float 精度和单点／体积求值顺序，包括该发布版 smooth 体积路径省略偏移的行为。

本轮验收分别检查八目标模块回归、可选依赖的实际 Mixin 应用、预设参数往返、真实 Tectonic Java 单点与体积结果以及 Rust 数值一致性。未提供依赖、版本不适用与主动关闭的基准需要显式区分；提供了依赖却没有执行对应检查时不能算通过。目前本节不声明最终通过数量、新包已经生成、实际整合包地形或帧时间已验收。源码范围与版本差异见[世界生成适配](../compatibility/worldgen.md)。

当前八目标候选包的构建标识为 `voxy-update-20261029`，均已通过生产构建和包内源码、版本与原生库校验。包内生产源码 SHA-256 为 `f9135b29a891076b0bcbd6bb4baba9bf957462eb50c3120440b79d21bd1bc2dc`。`lib/SHA256SUMS.txt` 按目标列出各标准 JAR 和合包的校验值。

`lib/vss-0.3.6.zip` 按 Minecraft 版本分目录收纳构建，附带构建清单和源码摘要。该合包只包含本仓库的 Fabric 版本。

## 旧版与社区适配阶段

> 本节对应世界生成修复之前的阶段构建，包括 `fabric-6a43e0bb24e8`；其中“本轮”“最终构建”均指当时那一轮。当前构建的复验范围以上节为准。

当前定位为候选移植版。编译、离线回归、真实依赖接口检查、GPU 合同和启动检查分别验收；标题画面初始化不代表实际游戏内地形和光影已经验收。实际游玩、长距离移动、传送、预测切换、重新进入世界及具体光影包的画面与帧时间仍需实机确认。

新增的 1.20.1 和 1.21.1 已完成生产编译、网络与模块回归、世界生成迁移、真实 Voxy / Iris 接口及 GPU 检查。两版专用服务器均完成启动、真实列预生成、缓存保存与正常退出；客户端完成标题初始化，并实际调用生产预测代码验证材质图集读取。1.20.1 的专用服务器使用 Java 17，配套社区 Voxy 的客户端使用 Java 21。测试中需显式启用的分配微基准、未提供的历史 Voxy 或可选世界生成模组输入，均单独记录为跳过。

本轮还同步了下午的 Voxy 根节点 / 遍历队列容量修复，并修复客户端世界生成快照缺少静态注册表、要塞首选生物群系标签未展开的问题。六个现代目标的完整原版植被和结构快照往返共 38 项针对回归通过；旧两版也使用实际网络注册表执行对应回归。植被与最终体素使用新的缓存身份，更新后会重新生成旧的空植被结果，已有原始地形采样仍可复用。
