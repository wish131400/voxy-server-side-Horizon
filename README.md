# Voxy Server Side Horizon

VSS 的独立 Fabric 移植版本。服务端读取或生成真实区块列并同步给客户端；客户端可以使用 Java / Rust 预测远处地形、植被和结构，再交给 Voxy 的统一体素渲染流程。

本仓库基于 VSS 0.3.6 的 NeoForge 版本继续开发。原 Forge 1.20.1、NeoForge 1.21.1 项目独立维护；它们的安装包不能直接用于 Fabric。

## 版本与依赖

每个 Minecraft 版本单独构建、单独验证，使用对应的 JAR。以下是接口检查和客户端启动使用的依赖组合；版本号相同但 Minecraft 目标不同的文件仍需按对应目标选择。

| 1.21.11 | 21 | 0.141.6+1.21.11 | 0.2.16-beta | 0.8.12+mc1.21.11 | 1.10.8+mc1.21.11 |
| 26.1 | 25 | 0.145.1+26.1 | 0.2.15-beta | 0.8.9+mc26.1.1 | 1.10.9+mc26.1.1 |
| 26.1.1 | 25 | 0.145.4+26.1.1 | 0.2.15-beta | 0.8.9+mc26.1.1 | 1.10.9+mc26.1.1 |
| 26.1.2 | 25 | 0.155.3+26.1.2 | 0.2.18-beta | 0.9.1+mc26.1.2 | 1.11.4+mc26.1.2 |
| 26.2 | 25 | 0.161.0+26.2 | 0.2.19-beta | 0.9.2+mc26.2 | 1.11.4+mc26.2 |
| 26.3 | 25 | 0.165.0+26.3 | 0.2.20-beta | 0.9.3-beta.1+mc26.3 | 1.11.7+mc26.3 |

Fabric Loader 最低版本为 0.20.1。26.1 行中的 Sodium / Iris 文件自身同时声明支持 26.1，不能只按文件名后缀判断兼容。

当前定位为候选移植版。编译、离线回归、真实依赖接口检查、GPU 合同和启动检查分别验收；标题画面初始化不代表实际游戏内地形和光影已经验收。实际游玩、长距离移动、传送、预测切换、重新进入世界及具体光影包的画面与帧时间仍需实机确认。

本轮六个目标均已通过生产编译和 JAR 校验；每个目标完成 396 项模块回归、118 项迁移检查及 2 项 GPU 检查，接口检查分别为 1.21.11 的 28 项与各 26.x 目标的 29 项，无失败。每个目标跳过 1 项需显式启用的分配微基准，以及 2 项缺少历史 Voxy 输入的可选检查。服务端启动、真实列预生成、缓存保存与正常退出，以及配套 Voxy / Sodium / Iris 的客户端标题初始化均已完成。

## 安装关系

- 服务端安装对应 Minecraft 版本的 Fabric Loader、Fabric API 和 VSS。专用服务器不需要 Voxy。
- 客户端安装对应版本的 Fabric Loader、Fabric API、VSS，以及 Voxy 要求的依赖。远景显示需要 Voxy。
- Mod Menu 为可选依赖，用于打开配置界面。
- 光影兼容按对应版本的 Iris / Voxy 实际接口验证，不以模组名称相同代替兼容检查。
- 服务端与客户端使用匹配的 VSS 协议。旧 Forge / NeoForge 的列体和世界生成格式不能与本移植版混用。
- 六个 Minecraft 目标的协议和列缓存格式也分别隔离，升级目标时不要混用旧列缓存。
- 未列出的 Voxy 社区分支、世界生成模组、地图模组和光影包没有获得本矩阵的兼容结论，保留的可选适配入口不等于已完成实测。

## 保留的能力

- 服务端真实列读取、预生成、持久缓存、传输、取消与脏列更新。
- 客户端 Java / Rust 地形、生物群系、植被和结构预测，精细体素缓存及近处优先调度。
- 预测和真实数据共同接入 Voxy 构网、细化、遮挡与绘制；真实数据优先，预测不写入 Voxy 的真实持久缓存。
- 世界、维度与种子身份隔离，以及真实列捕获和预测交接。

JAR 内包含 Windows x64、Linux x64 / ARM64、macOS Intel / Apple Silicon 的 Rust 库。Linux 库以 glibc 2.28 为基线，macOS 库以 11.0 为基线；这些是原生库的构建要求，Minecraft、Java 和图形驱动仍有各自的系统要求。

## 构建

1.21.11 使用 Java 21：

```text
gradlew remapJar
```

26.x 使用 Java 25，并指定目标，例如：

```text
gradlew jar -PmcTarget=26.1.2
```

标准产物位于 `lib`，例如 `vss-0.3.6-fabric-1.21.11.jar`。文件名不追加临时修复后缀，构建标识和源码摘要写入 JAR 清单。

`lib/vss-0.3.6.zip` 按 Minecraft 版本分目录收纳构建，附带构建清单和源码摘要。该合包只包含本仓库的 Fabric 版本。

## 源码组织

- `src/main`：共享调度、网络、缓存、预测核心，以及 1.21.11 实现。
- `src/versions/mc26`：26.1 系列及后续版本的差异实现。
- `src/versions/mc262`：26.2 开始的差异实现。
- `src/versions/mc263`：26.3 的世界生成与渲染差异实现。
- `tools/rust/vss-native-core`：共用的 Rust 原生计算与 JNI 接口。

构建时，同一路径的类只选择一个实现，优先使用更具体的版本目录。不能用扩大元数据版本范围的方式跳过接口验证。
